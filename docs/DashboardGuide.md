# VertexERP AI - BI Dashboard Builder & Visualizations Guide

## Overview
The **BI Dashboard Builder** allows enterprise users to design, customize, and publish drag-and-drop analytics dashboards with customizable widget visualizations and real-time data feeds.

---

## Supported Visualizations & Widget Types
- **Bar Charts**: Comparative metrics across periods, departments, or categories.
- **Line Charts**: Time-series historical trends for financial, attendance, or telemetry data.
- **Pie & Donut Charts**: Proportional distribution breakdown for leave types, department headcount, or scrap sources.
- **Area Charts**: Cumulative financial and inventory value progression.
- **Scatter Charts**: Correlation analysis for machine speed vs scrap rate or experience vs performance.
- **KPI Metric Cards**: High-impact numerical cards featuring target vs actual variance and trend badges.
- **Data Tables**: Paginated tabular summaries with column sorting and filtering.
- **Heatmaps**: Plant work center shift load and warehouse aisle pick intensity previews.

---

## Step-by-Step Dashboard Builder Workflow
1. Navigate to **BI Dashboard Builder** (`/analytics/builder`).
2. Specify Dashboard Title, Description, and Scope (`EXECUTIVE`, `DEPARTMENT`, `BRANCH`, or `GLOBAL`).
3. Select Visualization Type and Data Source domain (`FINANCE`, `HR`, `CRM`, `INVENTORY`, or `MANUFACTURING`).
4. Enter Widget Title and click **Add Widget to Canvas**.
5. Click **Save BI Dashboard** to publish the dashboard across the enterprise tenant.
